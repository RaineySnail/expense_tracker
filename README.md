# expense-tracker

Консольный трекер расходов на Python. Записывай, на что потратил деньги, смотри список и итоги по категориям. Данные сохраняются в JSON-файл, поэтому не пропадают после закрытия программы.

## Возможности

- **Добавление расходов:** сумма, категория, заметка. Дата ставится автоматически.
- **Просмотр списка:** нумерованный список всех расходов с датой.
- **Удаление** расхода по номеру.
- **Итоги по категориям:** сумма трат в каждой категории и общая сумма.
- **Автосохранение** в файл `expense.json` (поддерживается кириллица, UTF-8).
- **Защита от неверного ввода:** буквы вместо числа, ноль, отрицательная сумма и неверный номер не ломают программу.

## Запуск

Нужен только Python 3, сторонние библиотеки не требуются.

```bash
python3 expenses.py
```

## Как устроен код

| Часть | За что отвечает |
|---|---|
| `Expense` | Один расход: сумма, категория, заметка, дата. Метод `to_dict()` превращает его в словарь для JSON. |
| `ExpenseTracker` | Список расходов: добавление, удаление, показ, итоги, сохранение и загрузка файла. |
| `ask_num()` | Спрашивает число, пока пользователь не введёт корректное значение. |
| `main()` | Меню программы в цикле `while True`. |
